# OrderSystem

一个用于学习和实践服务端业务开发的订单系统项目，重点围绕数据库设计、事务处理、并发控制和性能分析展开。

## 项目目标

-   熟悉用户、商品、订单和库存等核心业务模型。
-   掌握 SQL、索引、执行计划和事务的实际使用。
-   处理并发下单、库存扣减、重复请求等一致性问题。
-   通过测试和性能数据验证设计，而不是只关注代码能否运行。

## 计划中的核心功能

-   用户与商品基础信息管理
-   创建、查询和取消订单
-   库存查询与扣减
-   订单状态流转
-   并发与异常场景测试
-   基础性能测试与问题分析

## 技术方向

项目将以 C++
服务端开发和关系型数据库实践为主。具体技术选型会随着实现过程逐步确定，并记录关键设计与验证结果。

## 开发原则

-   先保证业务正确性，再进行性能优化。
-   重要行为通过自动化测试验证。
-   性能结论以可复现的测试数据为依据。
-   逐步完善设计，不为追求复杂架构而提前拆分服务。

## 项目状态

项目处于初始阶段，功能与技术方案会随着开发持续更新。
